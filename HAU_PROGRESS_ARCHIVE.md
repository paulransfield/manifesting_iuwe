# Hau Whanau — Live Progress Archive

The [hau.whanau.tv public community archive](https://hau.whanau.tv/) is the dated bridge between the operating manual and the current GitHub living book. It is where the project continued to record progress, publish learning resources, and make the 360° teaching-to-learn / learning-to-teach work visible between January and July 2026, when repeatedly repaginating the operating manual was slow and impractical.

## Read the three sources together

| Source | Primary role | Time-aware reading rule |
|---|---|---|
| [Operating manual — public PDF](https://cdn.whanau.tv/wb00_manual_foreword_v01_82a4f75315.pdf) | Broad operating foundation: history, pedagogy, platform proposition, economics, governance, and roadmap | Treat it as the baseline document, not the final record of later implementation. |
| [Hau Whanau archive](https://hau.whanau.tv/) | Dated public progress record and living teaching-resource archive | Inspect posts, categories, and their visible dates before deciding a component was not built or published. |
| [Manifesting IUWE living book](https://github.com/paulransfield/manifesting_iuwe/) | Current architectural and implementation map, including ī-puāwai | Read it as the evolving proof-of-architecture record, not a substitute for the source materials it links. |

## Reading boundary

A source being absent from one document is not proof that it does not exist. Conversely, a claim appearing in a progress post is not automatically independent verification of performance, rights, consent, learner outcomes, or future scale. The right question is: **which source makes which claim, when, and what further evidence is needed?**

Use the [AI reading guide](./AI_READING_GUIDE.md) for the full layperson prompt that applies this discipline across all three sources.
